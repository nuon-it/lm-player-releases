# LM Player Releases & Auto-Update Distribution

Repository ini merupakan kanal distribusi publik resmi untuk instalasi dan auto-update aplikasi **LM Player** (Nuon / Melon).

## 📥 Download Installer Terbaru

Silakan kunjungi halaman **[Releases](https://github.com/nuon-it/lm-player-releases/releases)** untuk mengunduh versi terbaru:

* **macOS** (Apple Silicon M-series & Intel):
  * Unduh file `.dmg` (contoh: `LM-Player-<version>-macos.dmg`)
  * Buka DMG dan geser ikon `LM Player` ke folder `Applications`.
* **Windows** (Windows 10 / 11 64-bit):
  * Unduh file `.exe` (contoh: `LM-Player-Setup-<version>.exe`)
  * Jalankan installer (Zero-UAC per-user installation).
* **Linux**:
  * Unduh file `.AppImage` (contoh: `LM-Player-<version>-linux.AppImage`)
  * Berikan permission executable (`chmod +x LM-Player-*.AppImage`) dan jalankan.

## 🔄 Seamless Auto-Update (Velopack)

Aplikasi **LM Player** dilengkapi sistem auto-update otomatis melalui [Velopack](https://velopack.io/).
Saat versi rilis baru diterbitkan di repository ini, aplikasi yang sedang berjalan pada perangkat Anda akan mendeteksi dan mengunduh pembaruan di latar belakang secara otomatis tanpa perlu mengunduh ulang secara manual.
